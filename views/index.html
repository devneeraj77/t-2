📖 REST API Specification

Content-Type: application/json / x-www-form-urlencoded
GET /api/issues/{project}

Query issues with filters like ?open=true, ?assigned_to=Name, or combined.

POST /api/issues/{project}

Submit new issue with issue_title, issue_text, and created_by.

PUT /api/issues/{project}

Mutate ticket details or mark open: false using _id.

DEL /api/issues/{project}

Permanently remove an issue by specifying _id.
