📖 API Reference & Endpoints

JSON Endpoints
GET /api/issues/{project}

Retrieve all issues on a project. Filter by any field in query string: ?open=true&assigned_to=Joe

POST /api/issues/{project}

Create an issue with required fields: issue_title, issue_text, created_by.

PUT /api/issues/{project}

Update an issue by providing _id and any changed fields.

DELETE /api/issues/{project}

Delete an issue with _id.
